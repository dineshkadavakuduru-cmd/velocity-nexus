# Game audio

The `.wav` files in this directory are **synthesized placeholders** generated by
`scripts/generate-sounds.cjs` (pure PCM: engine hums, UI blips, noise-based
crash/screech/wind, soft ambient pads). They exist so the game boots with zero
404s and audible feedback without binary assets in git.

Replace them with real recordings at any time — keep the same filenames, since
`src/lib/audio.ts` references them:

- engine-idle.wav, engine-rev.wav, engine-mid.wav, engine-high.wav
- tire-screech.wav, crash.wav, nitro.wav, wind.wav
- countdown-beep.wav, race-start.wav, victory.wav, defeat.wav
- ambient-music-1.wav, ambient-music-2.wav

`Howl` is configured with `onloaderror` handlers, so a single missing file
degrades to silence instead of crashing the game.
